### Every bus name an app gets is checked

- The numbered names SAM adds to a bus name an app may own (for KDE apps
  that start several times, `org.kde.kdenlive-3`) are now checked like the
  name itself: one that is a service starting on demand or another app's
  name is left out. Only the exact tray names SAM chooses skip the check,
  no longer every name that starts like one.
