### The app icon names its real source

- The README said SAM's icon is based on Arcticons (CC BY-SA 4.0). It is
  based on the seal from Microsoft's Fluent Emoji (flat style, MIT), found
  through Iconify. The README now says so, and THIRD-PARTY-LICENSES.md, which
  every package installs, carries Microsoft's copyright notice and the MIT
  license text.
