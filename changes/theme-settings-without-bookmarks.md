### Theme settings no longer show your file chooser's bookmarks

- With *Host theme settings* (on by default), an app with a private home
  sees your GTK folders read-only, so it matches your desktop. These
  folders also hold the file chooser's bookmarks and server list, which
  name your folders and servers. The app now sees them as empty, unless
  you grant the folder itself.
- The security page now says what else a private home shows besides your
  granted folders: your fonts and, with that switch, your theme settings,
  icons and themes. It said "only the folders you granted".
- The security page used the old name *Local network only* for *This
  computer only*.
