### A room refuses a place that was moved away while it was built

- Room service, which builds the sandboxes that programs in an app ask for,
  now also ends a room when one of its places is no longer the mount
  Bubblewrap made there, or is reached through a link. Before, a program
  outside the room that can write the folder holding a place could move
  the place away and put the same file back at its name; the room then
  showed that file without the protection of its mount.
