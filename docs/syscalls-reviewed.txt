# Every syscall of the Linux kernel, reviewed for SAM's baseline filter.
# The filter is a deny list: a syscall the kernel adds later is allowed
# until it is reviewed. The test every_known_syscall_has_been_reviewed
# fails when the kernel headers name a syscall missing here, so a new one
# is looked at: block it in crates/sam-runner/src/kernel.rs if it can harm
# the host or reach outside the sandbox, then add it below. The test
# the_review_list_matches_the_filter checks every status against
# the filter itself.
#
# name<TAB>status, one of:
#   allowed                          the filter lets it through
#   blocked                          always refused (EPERM)
#   blocked unless nested sandboxes  refused unless the app may run nested
#                                    sandboxes (Chromium, Electron, WebKit),
#                                    which need namespaces and mounts
#   blocked by the strict filter     refused only with the strict filter on
#                                    (off by default)
#   limited                          some uses refused: ioctl typing into the
#                                    terminal (TIOCSTI, TIOCLINUX); socket
#                                    and socketpair families other than
#                                    local, internet and netlink (Bluetooth
#                                    with its switch);
#                                    clone into a new user namespace, unless
#                                    the app may run nested sandboxes
# clone3 keeps its flags in memory no filter can read, so without nested
# sandboxes it is refused as a whole, answering "not implemented" (ENOSYS)
# so the C library falls back to clone (review K-2, as in Flatpak).
# Apart from this list, every call through the x32 ABI is refused. 32-bit
# x86 calls end the process, except for an app whose start program is
# 32-bit: there they get the same statuses through their own numbers
# (review K-3), apart from socketcall, whose socket family the filter
# cannot read.
# Reviewed 2026-11-16 against the headers of Linux 6.x (x86_64 and the
# generic table aarch64 uses); statuses made exact 2026-11-19 (audit
# S-F10), with clock_adjtime, quotactl_fd, fspick and mount_setattr now
# blocked like their siblings; open_tree_attr (Linux 6.15) on 2026-11-25
# (review R67).
