# Reports

Every report SAM's checks have written, newest first: the version reports
(tests, line coverage, timings and dependencies of one state of SAM, made
with `make report`), the mutation runs, the runs of real AppImages, the
security review and the privacy check. The pages under Trust SAM always
show the newest report of each kind; here are all of them, so anyone can
see how SAM changed and check a claim against the report it came from.
